# Agent harnesses

## Sequence: **5/22**
- Utterance: An agent harness provides the infrastructure that supports and governs agent execution. It supplies objectives, constraints, behavioural guidance, and runtime context, and connects the agent to applications, APIs, data sources, and services. It enables authorised actions and returns observations to the reasoning process, maintains task state, interaction history, and retrieved information, and enforces access controls, operational boundaries, and human supervision. It makes relevant personal context available during reasoning and execution.
