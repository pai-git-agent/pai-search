# Vendor evaluator in the example

## Sequence: **10/19**
- Utterance: In the article’s example, a user who regularly evaluates vendors requires verifiable evidence for material claims, prioritises long-term reliability over short-term savings, considers total cost of ownership, and expects significant risks, assumptions, and trade-offs to be explicit. The agent learns these principles through vendor assessments. When the user later evaluates cloud service providers, the principles offer a starting point and the evidence changes to service-level commitments, security controls, scalability, migration costs, and long-term dependency.
