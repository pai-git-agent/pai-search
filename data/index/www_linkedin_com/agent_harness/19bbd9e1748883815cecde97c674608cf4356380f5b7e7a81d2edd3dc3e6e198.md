# Agent harness

## Sequence: **8/19**
- Utterance: An agent harness provides the infrastructure for agent execution. It supplies objectives, constraints, behavioural guidance, and runtime context, integrates applications, APIs, data sources, and services, enables authorised actions, returns observations to the reasoning process, maintains task state, interaction history, and retrieved information, and enforces access controls, operational boundaries, and human supervision. Its responsibilities may overlap with those of models and agents in a product. It makes relevant memory available during reasoning and execution, helping an agent avoid repeated questions, respect established preferences, recognise recurring mistakes, and maintain continuity.
