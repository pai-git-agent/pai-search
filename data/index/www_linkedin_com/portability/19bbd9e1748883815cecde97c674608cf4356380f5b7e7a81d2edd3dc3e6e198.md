# Portability

## Sequence: **7/22**
- Utterance: Portability lets an individual carry accumulated knowledge, preferences, methods, and decision principles across tasks, tools, domains, and service platforms. Across domains, judgment can inform unfamiliar problems when the system distinguishes enduring principles from local habits and exceptions and assesses each preference’s relevance. Across platforms, continuity can persist as the user changes models, applications, or providers. A receiving system must understand transferred context and how to use it, which requires structured context transfer, semantic interoperability, and contextual adaptability beyond syncing conversation archives. Portability makes accumulated context a durable resource even as access technology changes.
